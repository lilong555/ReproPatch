# P1-02 任务输入锁定

状态：**已完成**。版本：0.2.0.dev1。Task 格式：2。

## 可用契约

- 仅接受 Task v2；旧版本明确给出迁移入口。
- 严格检查嵌套字段、类型、预算与固定 CTest 模板；清单限制为 128 KiB、深度 12，拒绝重复键、
  anchor/alias、自定义 tag 与未知字段。
- 静态校验不创建 Run，不调用 Git、Docker、网络、模型或编译器。
- 动态冻结查询真实完整 commit、Git 对象格式、镜像 ID/平台，并展开 readable/editable/protected。
- 显式路径必须存在于固定 commit，editable 必须是 readable 子集且不与 protected 相交。
  所有 CMakeLists.txt 和 `.cmake` 文件均受保护；symlink/gitlink 被拒绝。
- readable 在固定 Git blob 上严格验证 UTF-8/NUL；非 UTF-8 路径拒绝替换解码，未授权的二进制构建资源保留。
- 专用根禁止互相包含或与源码仓库重叠；仓库子目录与错误输出根在写入 Run 前拒绝，普通及 bare 仓库根均可用。
- 原始 YAML hash 与规范执行契约 hash 分开保存；集合按 Unicode 码点排序，位置与 retain 不进入执行 hash。
- 运行报告、`task.original.yaml` 与 `task.resolved.json` 使用一次加载后的不可变输入。
- 示例生成器读取真实 commit/image，不重置原仓库；CLI 不再允许覆盖 Task 镜像。
