自动路径只使用公开 SDK Runner；不维护第二套模型协议、手写 HTTP 或模型 worker。
自有 fixture 不是第三方历史 bug，也不能用于估计模型修复率。
所有实验只记录真实结果，模型费用未知时不填零；远程创建/推送与付费调用按操作者的显式授权执行。
