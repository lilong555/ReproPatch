# 完整输入 Checkpoint 与受控暂停

对应版本：**0.3.0.dev2，Task v2**。P2-02 的历史验收结果；当前有限恢复契约见 [P2-03](P2-03.md)。
目标约束见 [状态与安全恢复](../specs/2026-10-19.2/docs/STATE_AND_RECOVERY.md)。

## 边界与产物

Checkpoint 仅在公开 call_model_input_filter 的完整输入边界生成：前轮所有已准入工具结束，
所属容器清理已确认，上下文与预算检查通过，下一请求尚未开始。第一次边界 step=0。
保存 input 与 instructions 的公开原生 JSON，保持 function_call/output 的 call_id 和 opaque continuation。
不保存 SDK 私有游标、pending 回调、客户端、凭据、进程或构建目录。

每个 checkpoints/<id>/ 目录包含 manifest.json、next-input.json、patch.diff、source-manifest.json。
manifest 字段固定为 schema_version、checkpoint_id、boundary、step_id、input_fingerprints、baseline、
native_next_input、patch、source_manifest、source_tree_sha256、counters、deadline_at。
引用一律使用 EvidenceRef 的 path/sha256/size_bytes；source_tree_sha256 是完整源码逻辑摘要，不替代文件 hash。
首次边界允许零字节补丁；有改动时仍核对允许文件、Git mode、UTF-8、规范 patch 与受控源码清单。
基线必须是本 Run 已确认的合格原始基线。指纹包含固定 Task/commit/image、Harness/Python/SDK 版本，
实现、工具 schema、模型配置和有效 instructions 的身份。CLI fake 的原始 JSON 脚本另存私有冻结引用。

目录 0700、文件 0600；创建目录后 fsync 父目录，各附件通过临时文件 flush/fsync、rename 及目录 fsync 保存。
同一 checkpoint_id 的路径独占创建，不覆盖既有文件。文件全部持久化后，一个 SQLite 事务同时提交
checkpoint_committed、checkpoints 行、runs.last_checkpoint_id、计数快照和 segment_open=0。
未提交文件没有恢复效力，不按文件名最大值猜测 Checkpoint；写入或事务失败不能返回成功暂停。

## 受控暂停

run 支持 --pause-after-step N，要求 1 <= N < max_steps，参数不进入 Task 验收 hash，不延长原始 deadline。
只在已完成 N 个累计 turn 后的下一完整输入边界触发；模型已正常结束时直接验收，不为暂停制造新请求。
暂停与 Checkpoint 在同一个事务中提交 INTERRUPTED/outcome=null，随后 HarnessPause 离开 Runner。
它不是 AgentStopReason 或新的 PAUSED 状态；SIGINT 是 CANCELLED，不会改成等待恢复的暂停。

成功暂停退出 0，summary 包含 paused=true、state=INTERRUPTED、outcome=null 和 checkpoint 引用。
源码及必需证据无论普通 retain 策略为何都保留；构建快照释放，容器必须确认删除，锁随后释放。
暂停不表示 ACCEPTED。缺失、版本/计数/期限/指纹不符或 hash 损坏的 Checkpoint 明确拒绝。

## 查询与验证

暂停报告从已提交 Checkpoint、累计状态和清理观察派生，不建立虚假最终事实。
核心 inspect/report 无需 SDK、模型或 key；删除派生文件后可重建，SQLite 字节和 outcome=null 保持不变。
报告导出失败返回 3，不将 INTERRUPTED 改成 FINISHED。损坏的输入边界不显示证据完整。

29 项专项测试包括 17 项核心格式/策略测试和 12 项 SDK/Harness 组合测试，覆盖全工具批次、
零字节补丁、opaque continuation、正常结束优先、暂停保留、目录持久化失败、事务拒绝、
真实进程在文件写完与数据库提交之间退出、孤儿文件、损坏与版本/计数/期限不符、导出失败及取消。
十九项真实 Docker 测试包含暂停场景：编辑和容器自查完成后，两个所属容器确认删除，修复源码仍保留。
完整回归为 291 核心、115 SDK、19 Docker；安装版另执行 406 项非 Docker 测试。
原始结果见 [测试报告](TEST_REPORT.md) 与 [证据核验](evidence/p2-02/artifact-checks.json)。

0.3.0.dev2 只生成安全边界并支持暂停，不执行 Resume、Trace Replay 或历史工具重做。
Phase 1 的 DeepSeek 证据属于 0.2.0rc1，本任务未重复付费调用，也不声明完整 0.3.0 已验收。
