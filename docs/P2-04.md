## 命令与读取范围

`replay RUN_ID --mode trace [--root DIR] [--json]` 从现有 SQLite 一致性快照读取按 seq 排序的事件。
默认输出人类可读时间线；JSON 输出包含 state/outcome、数据库与事件版本、事件截止、证据检查及引用。
只投影宿主领域字段，模型原生输入/输出、instructions、opaque continuation 和外部 producer trace 不展开。
终端控制字符和不可信文本经过转义；它们不会变为工具动作或执行指令。

`export-trace RUN_ID [--root DIR] [--output FILE]` 输出原 v1 事件 JSONL，不添加伪事件头。
默认 stdout；显式目标是原 Run 之外的新文件，通过独占发布拒绝覆盖、链接及路径穿越。
数据库缺失、未知、损坏或没有 Run 事件时拒绝，不创建空成功导出。
旧 kind 审计可按原版查看，event_format/evidence_complete 为未知；不转换或导出成新信封。
历史 schema v1 事件仍可按原信封导出，不迁移原数据库。

两条命令不创建 Run、不开写连接、不取得控制器 flock、不调用模型、Git、Docker、工具或 resume。
缺失或伪造的派生 JSONL、report 和 run.json 不参与恢复状态判断；不从 JSONL 修补数据库。
附件引用按大小与 SHA-256 核验；缺失或不符时仍展示已知轨迹，并返回 3/EVIDENCE_UNVERIFIABLE。
权威 state/outcome 保持原值，查询成功、证据完整或旧日志中的成功文字均不表示可继续或已修复。

## 选定故障门槛

`scripts/check_recovery_gate.py --output DIR` 运行 13 个明确命名的 ScriptedModel 场景。
JUnit 属性将用例与实际 Run 关联；完整数据库、原生引用、候选、日志和只读轨迹随证据保留。
故障前缀来自同一次运行的已提交事件，仅供对照查看，不是独立 baseline 试验或恢复数据库。

| 分类 | 场景 | 结果 |
| --- | --- | --- |
| 安全恢复 | 受控暂停、安全 Checkpoint 后进程退出、Agent 时间耗尽但安全候选仍可独立验证 | 3 个 ACCEPTED |
| 明确失败 | 请求结果未知、回复后工具前、编辑后边界前、Checkpoint 文件未入库、最终回复未交接 | 5 个 RECOVERY_FAILED |
| 明确失败 | Checkpoint 损坏、源码分歧、清理未确认、恢复阶段再次中断 | 4 个 RECOVERY_FAILED |
| 控制器拒绝 | 原 writer 持锁 | 1 个拒绝接管，原 Run 继续保持安全暂停 |

9 个失败场景在接管后没有新增模型 turn 或工具调用；已完成 tool_call_id 不重复。
原始 deadline 不重设，steps/工具额度及已知/未知用量分别保留。
损坏 Checkpoint 负例保留实际坏文件及不可核查标记，不修补附件来制造绿色证据。
清理不确定与主要失败分别记录；安全失败单列，不计入修复成功率。
本门槛没有付费模型请求，也不估计真实模型能力或一般恢复成功率。

## 验收与边界

T10 的 18 项核心测试在查询期间禁止创建子进程、加载 SDK、调用模型/执行工具或恢复，
并比较原 Run 全部文件内容；覆盖缺失/伪造派生产物、开放片段、暂停、缺失原生/嵌套附件、
精确 JSONL 导出、既有目标/链接/穿越拒绝、坏数据库、历史格式及不可信终端文本。
干净核心 wheel 无 SDK 执行 JSON/Markdown replay、stdout/文件 export-trace，原 Run 文件保持不变。
有限恢复、真正存活容器的所属清理和原修复—验收链路继续通过实际 Docker gate。

完整回归为 **483 项**：315 核心、147 SDK、21 Docker；安装版另执行 462 项非 Docker 测试。
13 项恢复 gate 是上述用例的指定重复执行，不加入唯一用例总数。
32 份当前报告含故意损坏的负例，另核对 64 份历史报告；计数及不可核查项均单列。
原始证据见 [测试报告](TEST_REPORT.md)、[恢复 gate](evidence/p2-04/recovery-gate/summary.json)
和 [发布核验](evidence/p2-04/release-audit.json)。

当前不提供 Execution Replay、Harbor、通用调度、跨版本恢复或未知副作用重做。
只读轨迹、同 Run 安全恢复与新 Run 独立验收具有不同边界；不承诺 Exactly Once。
Phase 1 的真实 DeepSeek 认证保持原版，本任务未新增 V-LIVE 或付费故障实验。
