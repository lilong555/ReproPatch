## 复验

需要 Python 3.12+、项目开发依赖、Git、可用 Docker daemon，以及本地验收镜像。
非 Docker 的真实 C++ 测试还需要宿主 CMake、CTest 和 g++；CMake/CTest 可安装至当前虚拟环境：

```bash
python -m pip install cmake
ruff check src tests scripts
ruff format --check src tests scripts
python -m pytest -m 'not docker' -q
python scripts/check_docker_gate.py
```

尚未构建镜像时，在具备软件源和镜像源访问条件的主机上执行：

```bash
python scripts/check_docker_gate.py --build
```

脚本保存 Git 身份、源码字节清单、Docker 版本、镜像 ID、doctor、测试日志、JUnit 及完整运行产物。
已有输出目录拒绝覆盖；Docker 缺失、构建失败、跳过和失败均不能得到通过结论。
