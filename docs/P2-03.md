# 有限 Resume 与未知片段安全失败

对应版本：**0.3.0.dev3，Task v2**。P2-03 的历史验收；当前只读轨迹和恢复门槛见 [P2-04](P2-04.md)。
权威目标见 [状态与恢复](../specs/2026-10-19.2/docs/STATE_AND_RECOVERY.md)。

## 恢复资格

`repropatch resume RUN_ID --root DIR [--pause-after-step N] [--json]` 只接管已有 Run。
完整 Run ID、私有控制目录、原数据库和 flock 均核对通过后，才提交接管与恢复次数。
活跃控制器不能被抢占；终态 Run 拒绝继续，旧 schema 可查询但不迁移或恢复。
容器核对以数据库已登记的 name、ID、Run 标签和镜像为依据；不得删除归属不符的对象。
即使工作区损坏或 wall 已耗尽，已登记容器仍进行有界必要清理。

只有 REPAIRING 或安全暂停的 INTERRUPTED、segment_open=0 且存在最新已提交 Checkpoint，才可继续。
冻结 Task/base/image、配置、Harness/Python/SDK、静态六工具 schema、instructions 和全部必要引用必须一致。
开放片段、Checkpoint 孤儿、历史模型回复、工具结果和旧 build 都不成为恢复资格。

## 原生输入与源码

SDK 继续接收保存的完整原生 input 和 instructions，保留 function_call/output 关联和 opaque continuation。
使用原配置的 Agent 和剩余 max_turns；不访问 SDK 私有游标，不添加第二套 Agent Loop。
fake 从被冻结的原生 JSON 脚本按 steps_used 取剩余 ModelStep，不重复已消费回复。
真实模型凭据只从原 key_env 重新读取；不允许 resume 更换任务、模型或预算。

恢复在新的自有 worktree 从固定 base 应用保存 patch，比较完整 SourceManifest 与逻辑摘要。
原 repair 树仍存在时先验证原登记身份及完整字节；第三方修改得到 WORKSPACE_DIVERGED，不 reset 或覆盖。
已验证的新树准备成功后释放原所属旧树；可丢弃工作区缺失时从完整 Checkpoint 重建。
未提交的下一编号目录保存为恢复诊断，不按目录最大编号选择恢复点，也不覆盖原孤儿附件。

## 预算、暂停与结局

创建时的 deadline_at 不变，停机时间消耗 wall。steps_used、tool_calls_admitted 和实际观察用量继续累计。
部分或缺失 token 字段保持未知，known_tokens 不丢失；不会因新 Runner 返回而补成零。
恢复成功与回到 REPAIRING 同事务；之后才允许新的模型请求或普通预算停止路径。
Agent 时间或 turn 耗尽时不请求模型；安全候选只使用原验证预留，无候选为 BUDGET_EXHAUSTED，
验证时间不足为 INCONCLUSIVE。未验 patch 保留，供显式的新 verify-patch Run 使用。

再次暂停的 N 是全 Run 累计目标，要求 steps_used < N < max_steps；不保留成后续控制器的暂停偏好。
成功暂停退出 0、INTERRUPTED/outcome=null；正常模型结束优先走独立验收。取消为 FINISHED/CANCELLED。

## 未知窗口与诊断

model_started 后没有完整模型结果时，RECOVERY_FAILED/MODEL_RESULT_UNKNOWN，不重发潜在收费请求。
回复已保存但工具轮次未关闭、编辑后或 Checkpoint 事务前退出时，OPEN_AGENT_SEGMENT，不补交或重做。
SDK 最终回复已存而控制器未交接时，也不重新调用模型。
PREPARING/REPRODUCING/VERIFYING 或上次 RECOVERING 中断后，不重执行该阶段，返回 UNSUPPORTED_RECOVERY_PHASE。
Checkpoint 损坏、身份变化或清理无法确认分别明确拒绝；主错误与清理错误同时出现时保留主因及清理诊断。

可写库提交 FINISHED/RECOVERY_FAILED。尽力保存的 recovery/<attempt>/unverified.patch 与源码清单
标记 verification_eligible=false，不能直接当作已验候选；保存失败列入诊断错误。
库不可读或不能提交时停止执行，尽力生成 recovery-error.json，database_updated=false；
回执不替代 SQLite，也不会创建空库、删除原库或从 JSONL 修复状态。
报告导出失败不重执行已提交终态，核心 report 可重建，原数据库字节保持不变。
