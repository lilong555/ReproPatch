# 领域审计与报告契约

Phase 1 版本：**0.2.0rc1，Task v2**。`run` 与 `verify-patch` 使用同一审计和导出路径。
0.3.0 的三表、预算与状态事务见 [P2-01](P2-01.md)，事件信封及派生导出契约继续适用。

## 权威记录

每 Run 的 `events.sqlite3` 使用 `user_version=1`，只包含 events 表：
`seq`、`timestamp`、`type`、`envelope_json`。SQLite 使用 DELETE journal 和 FULL synchronous。
事件信封包含 schema_version、seq、run_id、UTC timestamp、type、step_id、tool_call_id、operation_id、payload。
事务分配已提交的连续序号；提交失败传播，不回退到 JSONL。时间不决定展示顺序。

模型开始记录原生 input 引用和已扣 turn；结束记录原生 output 引用及已观察 usage。
整批准入记录 provider_call_id 与本地 `s000001.t01` 的对应。命令使用独立 UUID，
command_started 保存实际 argv/cwd，command_finished 引用私有 CommandResult JSON，
stdout_log/stderr_log 分别指向原始双流文件。工具结果与最终模型文本保存附件，原生 continuation 不在 Markdown 展开。
外部 producer trace 保持未验证的 opaque 附件，不进入可信命令、测试或用量统计。

## 终结与导出

运行依次完成必要清理、检查证据、保存最终事实附件、提交 FINISHED 的 state_changed 事件。
`evidence/final-result.json` 保留完整结果及引用，终态事件记录它的大小和 SHA-256。
终态事务失败时没有可信 FINISHED；派生报告不能补交或猜测结局。
Phase 1 不包含 runs/checkpoints 表，不承诺 SIGKILL 后恢复执行。

导出读取已提交事件快照，生成 events.jsonl，再分别原子替换 report.json、report.md 和 run.json。
文件为 0600，临时文件 flush/fsync 后 rename，并 fsync 父目录。跨文件不承诺原子事务。
run.json 的 export_metadata 保存事件截止序号、导出时间与产物引用，仅为派生索引。

导出失败保留已提交 outcome/reason_code，本次命令返回 3 / ARTIFACT_EXPORT_FAILED。
JSONL 无法导出时，可写的 JSON 报告将 trace 置 null；inspect 显示 artifacts_complete=false。
已提交事实与 SQLite 不依赖这些派生文件；报告、JSONL 或索引丢失后可以重新导出。
证据缺失或 hash 不符保持原结局，同时显示 EVIDENCE_UNVERIFIABLE，不伪造通过或新的测试失败。

## 查询

```bash
repropatch inspect RUN_ID --root DIR --json
repropatch report RUN_ID --root DIR --format json
repropatch report RUN_ID --root DIR --format md
```

RUN_ID 必须是完整 32 位小写十六进制 UUID；默认根为 cwd 的 `.repropatch/runs`。
inspect 不写文件，显示最后已提交阶段、结局、最后事件、证据及导出完整性。
没有终态时 outcome=null；磁盘上自报成功的 report.json 不影响查询。
report 在 Run 排他锁下重新导出，不运行 Git、Docker、模型或仓库代码。
REJECTED、ERROR 等已结束 Run 的报告正常读取仍退出 0；读取、证据或导出失败退出 3。
非法 ID 退出 2；不存在、损坏、链接或未知版本的数据库不会被创建或替换。

历史 user_version=0 / kind 审计按原格式查询，明确标记 LEGACY。
有可核验历史报告时原样展示，不迁移为新信封、不声称可重建或恢复。

## 报告与诊断

JSON / Markdown 均来自终态引用的同一事实，包含执行身份、来源、基线、独立观察、清理、用量及限制。
测试区分通过、失败、未运行、skip、timeout、crash 和证据无效；命令列出状态及 stderr 附件。
未知 token / HTTP 次数保持 null；fake 的合成标志与外部未受控生成分别披露，费用不估零。
Markdown 转义外部字符串，原始 provider 内容和 producer trace 不作为 Markdown 内容执行。
内部异常及 cause/traceback 保存在私有 diagnostics，已知模型 key 脱敏；终端只给短原因。

验收结果与原始证据见 [测试报告](TEST_REPORT.md)；完整 0.2.0 的真实模型认证属于 P1-08。
