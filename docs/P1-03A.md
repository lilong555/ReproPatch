## SourceManifest

清单 JSON 只有 `schema_version: 1` 与 `files`。每项包含 `path`、`sha256`、`size_bytes`、`git_mode`，
按规范 UTF-8 相对路径的 Unicode 码点排序；mode 为 `100644` 或 `100755`。
内容哈希直接来自文件原始 bytes，二进制资源、空文件和可执行文件均参与整树身份。
逻辑 `source_tree_sha256` 是整个清单的规范 JSON SHA-256：键排序、紧凑分隔符、UTF-8、无末尾换行。
EvidenceRef 的 SHA-256 则对应实际保存文件的 bytes，包含其格式和末尾换行。

单源文件上限 16 MiB，整树上限 256 MiB。Git 对象元数据在 checkout 前预查；
每次检查还遍历完整文件系统，不忽略 untracked/ignored。
链接、hardlink、特殊文件、额外空目录、文件集合或 Git mode 变化均拒绝。
快照只导出源码，不包含 `.git`；普通文件 0644、可执行文件 0755、目录 0755。

## 受控 Git 与文本编辑

本地 Git 配置禁止 include/includeIf、活动 filter、fsmonitor、自定义 hooksPath、额外 worktree 配置、
external diff/textconv 和 partial clone/promisor。Git 操作使用隔离环境与固定禁用参数。
提交中的层级及宏 `.gitattributes` 由 Git 在私有 index 上解释，拒绝 filter；原 index 不变。

工作树记录实际 Git manager/common 路径、UID、根目录身份与双向指针；清理前复核这些身份。
文件读取使用 `O_NOFOLLOW`，核对打开前后身份；编辑逐级固定目录 fd，原子替换时不重新跟随父路径。
文本工具只访问 frozen readable/editable 集合，单文件编辑上限 1 MiB，预览上限 64 KiB。
输入必须是 UTF-8、无 NUL，旧串只能匹配一次；BOM、CRLF、末尾换行和权限按原内容保留。
受控编辑之外的内容或权限变化触发 `SOURCE_CHANGED`，运行以错误结束。

## 候选与独立验证

候选只接受已有、授权、非 protected 的 C/C++ 文本内容修改。新增、删除、重命名、mode 变化及二进制
补丁均拒绝。规范 diff 使用固定前缀、完整 OID、Myers 算法与三行上下文；原始 patch 最大 8 MiB。
超限候选明确拒绝，不把截断数据保存为可验证补丁。

`CandidatePatch` 固定 base commit、patch 引用、manifest 引用、逻辑源码 hash 和变更文件集合。
EvidenceRef 是 Run 内规范相对路径、完整字节数和 SHA-256；逃逸、symlink 或内容不符视为证据损坏。

独立工作树从同一 base 创建，先以 Git 检查 numstat/summary、授权范围和 patch 可应用性，再实际
`git apply` 保存的 bytes。仅在完整 SourceManifest 与候选相同、再次导出的规范 patch 也逐字节相同时，
报告 `candidate_roundtrip_verified=true` 并启动独立编译。
Git 属性导致换行转换而无法往返的候选不能通过。每次评估前后核验工作树和快照，结束前再次校验候选引用。
