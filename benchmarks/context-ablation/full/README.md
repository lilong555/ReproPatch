# 五组上下文完整实验

19 个 fmt 缺陷任务、5 组策略、每组每题重复 2 次，共 190 条轨迹。基线的观测冷评分通过率为 89.5%，平均总 Token 为 269,824，在本批次五组中通过率最高、用量最低。诊断提取与结果去重均为零触发，状态感知压缩仅触发一次；策略收益的评估继续依赖实际触发覆盖与配对运行证据。

## 逐题失败

失败集中在 6 道题，包含 8 条构建失败、22 条测试失败；其中 5 条测试失败同时涉及 P2P 回归。30 条失败轨迹均在 24 次请求预算用尽时停止，另有 21 条预算用尽的轨迹通过独立冷评分。

[逐题结果与失败明细](failures.md) 包含 19 题各组结果、30 条失败记录、原始轨迹入口，以及已读取原轨迹的三例具体编译错误、段错误和断言差异。日志核对状态逐条保留。
